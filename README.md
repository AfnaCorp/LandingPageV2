# JLOOW Landing Page

Copie autonome de la landing page JLOOW, prévue pour être partagée et modifiée sans toucher au dossier `studio`.

## Lancer le projet

```bash
npm install
npm run dev
```

La page sera disponible sur `http://localhost:9010`.

## Notes

- La page principale est dans `src/app/page.tsx`.
- Les boutons `Se connecter`, `Inscription` et l'accès final au quiz sont volontairement désactivés dans cette version partageable.
- Les assets de la landing sont dans `public/`.
- Les pages légales utilisées depuis le footer sont gardées pour éviter les liens cassés.
